# Имитатор выхода аналогового датчика 0–5 В

## 1. Описание устройства

Устройство предназначено для имитации выходного сигнала аналоговых датчиков напряжения в диапазоне **0–5 В**. Может использоваться для тестирования, отладки и проверки работоспособности электронных устройств, контроллеров и измерительных систем без подключения реального датчика.

Устройство поддерживает установку постоянного выходного напряжения и генерацию синусоидального сигнала. Управление осуществляется через интерфейсы USB CDC, UART или CAN.

## 2. Основные характеристики

| Параметр | Значение |
|---|---|
| Количество выходных каналов | 4 |
| Диапазон выходного напряжения | 0–5 В |
| Режимы работы | Постоянное напряжение, синусоидальный сигнал |
| Интерфейсы управления | USB CDC, UART, CAN |
| USB/UART-преобразователь | CH343 |

> **Примечание:** диапазон выходного напряжения указан как номинальный. Точность, разрешение, максимальная частота сигнала и допустимая нагрузка определяются аппаратной реализацией устройства.

## 4. Интерфейсы управления

Управление устройством возможно через следующие интерфейсы:

- **USB CDC** — виртуальный последовательный порт, позволяющий обмениваться командами с устройством через USB.
- **UART (CH343)** — последовательный интерфейс, доступный через USB-UART-преобразователь CH343.
- **CAN** — обмен управляющими данными по шине CAN с использованием идентификатора сообщения `0x00000001`.

Для USB CDC и UART используется текстовый протокол команд. Для CAN используется передача параметров в виде байтового сообщения.

## 5. Протокол управления через USB CDC / UART

Команды передаются в текстовом виде. Параметры разделяются пробелами.

### 5.1. Установка постоянного напряжения

**Формат команды:**

```text
set_voltage <voltage_mV> <channel>
```

| Параметр | Описание |
|---|---|
| `voltage_mV` | Заданное выходное напряжение в милливольтах |
| `channel` | Номер выходного канала |

Напряжение задаётся в милливольтах: `1000` соответствует `1 В`, а `5000` — `5 В`.

**Пример:**

```text
set_voltage 2500 1
```

Команда задаёт напряжение 2,5 В на канале 1.

### 5.2. Генерация синусоидального сигнала

**Формат команды:**

```text
set_sine <freq> <amp_mV> <mid_point_mV> <channel>
```

| Параметр | Описание |
|---|---|
| `freq` | Частота синусоидального сигнала |
| `amp_mV` | Амплитуда сигнала в милливольтах |
| `mid_point_mV` | Средний уровень сигнала (смещение) в милливольтах |
| `channel` | Номер выходного канала |

**Пример:**

```text
set_sine 10 1000 2500 1
```

Команда задаёт на канале 1 синусоидальный сигнал со следующими параметрами:

- Частота: 10 Гц.
- Амплитуда: 1000 мВ (1 В).
- Средний уровень: 2500 мВ (2,5 В).
- Теоретический диапазон выходного напряжения: 1,5–3,5 В.

> **Важно:** в этой документации предполагается, что `amp_mV` обозначает амплитуду от среднего уровня до пика, а не размах сигнала от минимума до максимума.

## 6. Протокол управления через CAN

Для управления по CAN используется сообщение с идентификатором:

```text
ID: 0x00000001
```

Формат полезной нагрузки:

| Байт | Поле | Описание |
|---:|---|---|
| 0 | `freq` | Частота сигнала |
| 1 | `amp_mV` | Амплитуда сигнала |
| 2 | `mid_point_mV` | Средний уровень сигнала |
| 3 | `channel` | Номер выходного канала |

Длина полезной нагрузки составляет **4 байта**.
